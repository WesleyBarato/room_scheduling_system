# Room Scheduling System

A modern room scheduling and access control system designed for educational institutions and training centers.

This project started as an internal solution for Senac Gravataí (Brazil) to manage classroom reservations, and is being designed to evolve into a complete commercial product.

The goal is to provide full visibility, automation, and secure access control for physical rooms.

---

# Live Vision

This system is not just a scheduler. It is a platform that will integrate:

• Room reservations  
• Real-time room usage display on TVs  
• QR Code-based room access  
• Tablet interfaces at each room  
• Access control and automation

---

# Current Version – V1 (Deployed and in use)

Core features:

• Create room reservations  
• View reservations by date and shift  
• Prevent schedule conflicts  
• Identify who reserved each room  
• Simple and fast interface  
• Real-time database integration (Supabase)

# Planned Versions (Product Roadmap)

## V2 — TV Dashboard Display

Goal:

Display room schedules on TVs placed in hallways.

Features:

• Real-time room status display  
• Current class and next class  
• Teacher name  
• Automatic updates

Purpose:

Improve visibility and reduce confusion.

---

## V3 — QR Code Room Access

Goal:

Allow teachers to unlock rooms using QR Code.

Features:

• QR Code generated after reservation  
• QR Code scanning using tablet or door reader  
• Secure room access validation  
• Prevent unauthorized access

Purpose:

Automate physical access control.

---

## V4 — Tablet Room Interface

Goal:

Install a tablet outside each room.

Features:

• Show current reservation  
• Show next reservation  
• Allow check-in  
• Display room availability

Purpose:

Improve on-site experience and automation.

---

Features:

• Authentication  
• Admin dashboard  
• Analytics
